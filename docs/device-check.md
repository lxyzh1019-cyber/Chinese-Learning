# The iPad check — before the girls use it every day

One sitting, on the iPad they will actually use, with a throwaway profile
state (Parent → Clear all progress, or a fresh browser profile). Nothing here
touches the cloud records unless you are online with the real profiles, so do
it offline first if you want to be safe, then once online.

Everything below was run in headless Chromium on 2026-09-09 and passed. What
Chromium cannot tell us is the iPad's audio, its scrolling inside overlays,
and what happens when the app is backgrounded mid-question — that is this list.

## 1. Flashcards keep prior progress (F1)
1. Clear a gate the quick way: none needed — just read gate 1's story once
   (stay 45 s), finish the flashcard deck for gate 1.
2. Close Safari fully, reopen. Gate 1's read count and Trace unlock must still
   be there (Games → Dynasty → Trace is open).

## 2. Sentence retry, leave, and resume at the same level (F2, F3, R2)
1. Start the gate 1 boss quiz, reach Phase 3, build one sentence in the wrong
   order, Check. The reveal card shows; "Try again" clears the chips; a correct
   rebuild says "well rebuilt" and pays nothing.
2. Every sentence shows a hint line under the instruction — either the
   English, or "Part of: …". If one has no hint, note the sentence.
3. Save & Exit mid-quiz. Switch to the other child and back. Resume → it
   reopens on the same phase and question.
4. If HSK2 is open on this profile, do the same from an HSK2 gate and confirm
   the result screen names HSK2.

## 3. Champion (R1)
1. On a profile with gates 1–5 cleared, tap the Champion Group 1 crown.
2. Finish it (it is long; a wrong answer or two is fine as long as accuracy
   stays above 90 %). The result must say **Cleared!** with a trophy line, the
   crown on the map must turn gold, and the hub's trophy count must read 1/4.
3. Tap the crown again and finish again: no second star payout.

## 4. Audio (C1)
Tap these in a story and listen: 听, 看, 打, 着, 东西, 他, 又, 故事. The voice
must say what the pinyin shows (dōngxi, not dōng-xī; tā "he"). Then background
the app for a minute, come back, tap another character: audio still plays,
the story still scrolls.

## 5. Games save and resume
1. Listen (HSK scope): answer 3, Save & Exit → toast "Progress saved…", stars
   unchanged, "Resume last activity" reopens at 4/10.
2. Match (HSK scope): flip a few, Save & Exit, wait five minutes, Resume: the
   round is the **Match** round, and finishing it can still earn stars.

## 6. Parent panel
The Parent button asks for the PIN before showing anything. Star edits still
ask. Clear all progress asks and says which player.

## 7. Assessment
Profile select → Assessment. Answer a few, Save & Exit, reopen: the same next
item. Turn Wi-Fi off, answer two more, Save; turn Wi-Fi on; the attempt shows
in History as saved. Do not open the same attempt on a second device.

## 8. Culture readings
Open any culture story: a strip of target words with pinyin and English sits
above the text (tap one to hear it), and each "Think about" question has a
Show answer button.

If any step fails, write down the step number and what the screen said — that
is enough to fix it from.
